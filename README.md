# LaunchOS

Premium landing page for LaunchOS — the AI-native operating system for Solana token teams.

## Deploy with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save.
5. GitHub Pages will publish `index.html` automatically.

The site is intentionally dependency-free, so no Node.js build step is required.
